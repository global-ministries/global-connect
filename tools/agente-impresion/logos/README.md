# Logos de las áreas

Pon aquí la mascota de cada área como BMP de 1 bit (blanco y negro, sin
compresión), con el nombre del área:

- `waumba.bmp` — Waumba Land
- `upstreet.bmp` — UpStreet

El agente la escala a la altura del encabezado de la etiqueta. Usa trazos
gruesos (la impresora tiene 8 puntos por mm). Si no hay archivo, la etiqueta
muestra solo el nombre del área. Reinicia el agente después de agregar o
cambiar un logo.
